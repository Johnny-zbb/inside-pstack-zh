# 深入 pstack

《Inside pstack》的中文译本，介绍技能、操作流程、原则、模型编排和验证方法。

[在线阅读](https://johnny-zbb.github.io/inside-pstack-zh/) · [英文原文](https://claude.ai/artifact/JNBnuspjGxGw3vW1k9sMiY)

## 内容与界面

报告包含 32 个任务技能与子代理条目、23 套操作流程和 24 条原则。版本、数字和评价保留英文原文的口径。

网站支持目录导航、技能检索、命令复制和一键深浅色切换。标题、正文和界面文字使用 HarmonyOS Sans，代码使用等宽字体。

## 本地预览

安装 Python 后，在仓库目录运行：

```sh
python -m http.server 8000
```

打开 <http://localhost:8000/>。网站使用原生 HTML、CSS 和 JavaScript，无需构建。

## 更新网站

修改文件后推送到 `main` 分支。GitHub Pages 从仓库根目录发布，`.nojekyll` 用于跳过 Jekyll 处理。
